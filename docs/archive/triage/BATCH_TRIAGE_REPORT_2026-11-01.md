## Surgical Implementation Details

### 1. ShortcutTrampoline Task Launch Race (BUG-059)
- **File**: `app/src/main/java/com/limelight/ShortcutTrampoline.java`
- **Mechanism**: Removed explicit `finish()` call prior to `startActivities(intentStack)`. Because `ShortcutTrampoline` is configured with `android:noHistory="true"` and the initial intent uses `FLAG_ACTIVITY_CLEAR_TASK | FLAG_ACTIVITY_NEW_TASK`, the Android system replaces the task and disposes of the trampoline automatically. This eliminates the race where early activity destruction detached the task on Android 16 and 17.

### 2. MediaCodec Decoder Failure Handling (BUG-060)
- **File**: `app/src/main/java/com/limelight/binding/video/MediaCodecDecoderRenderer.java`
- **Mechanism**: In `doCodecRecoveryIfRequired`, caught `IllegalStateException` during decoder reset and initialized `recoveryFailure` while marking `stopping = true`. Ensured `codecRecoveryThreadQuiescedFlags = 0` and `codecRecoveryMonitor.notifyAll()` always execute, preventing deadlocks for other decoder threads. Released the monitor lock before reporting the error through `crashListener.notifyCrash(recoveryFailure)`. In `tryConfigureDecoder`, converted `IOException` to `IllegalStateException` under `throwOnCodecError`.
- **Line Ending Integrity**: Preserved existing CRLF line endings. Verified `git diff --ignore-cr-at-eol --stat` matches `git diff --stat`.

### 3. Upstream Watch Sources Synchronization
